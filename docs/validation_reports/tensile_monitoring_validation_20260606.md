## Technical Validation

### σW'' Tensile Instability Criterion

The implementation uses the stress-kernel second derivative product criterion:
- **σW'' > 0**: Stable (repulsive force dominates)
- **σW'' < 0**: Unstable (tensile clumping risk)

### Adaptive ε Control

The Monaghan artificial stress coefficient ε is dynamically adjusted:
- **ε_min** = 0.0 (stable flow)
- **ε_max** = 1.0 (severe instability)
- Scales linearly with instability ratio above threshold
