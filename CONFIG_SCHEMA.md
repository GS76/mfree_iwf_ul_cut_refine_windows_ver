# Runtime Configuration Schema (JSON)

This project supports configuration-driven runs via a JSON file loaded at runtime. The configuration file is designed to be stable for version control (deterministic key ordering when generated by `--dump-config`) and validated at load time.

## CLI

- Run from config: `mfree_iwf --config <path-to-json>`
- Dump a complete default config: `mfree_iwf --dump-config <path-to-json>`
- Optional flags that still apply: `--smoke`, `--cooldown`, `--cooldown-remove-tool`, `--cooldown-hconv <W/m^2/K>`, `--all-steps`

## Top-Level Object

| Field | Type | Required | Notes |
| :--- | :--- | :---: | :--- |
| `schema_version` | integer | Yes | Must be `1`. |
| `name` | string | No | Free-form identifier for logs/version control. |
| `io` | object | Yes | Output controls. |
| `model` | object | Yes | Scenario selection. |
| `workpiece` | object | Yes | Workpiece geometry and discretization. |
| `tool` | object | Yes | Tool geometry, placement, motion, contact/friction. |
| `time` | object | Yes | Time-stepping controls. |
| `numerical` | object | Yes | SPH/correction constants. |
| `material` | object | Yes | Material library selection. |
| `plasticity` | object | Yes | Plasticity model selection and controls. |
| `thermal` | object | Yes | Thermal model selection and controls. |
| `multiresolution` | object | Yes | Multi-resolution layout (models 2/3). |
| `adaptivity` | object | Yes | Dynamic refinement controls (model 3). |

## `io`

| Field | Type | Required | Allowed / Range | Notes |
| :--- | :--- | :---: | :--- | :--- |
| `output_dir` | string | Yes | non-empty | Folder relative to the working directory. |
| `clear_output_dir` | boolean | Yes | | Deletes `*.vtk` and `*.txt` files in `output_dir` at startup. |
| `num_print` | integer | Yes | `>= 1` | Number of output frames. |
| `all_steps` | boolean | Yes | | Forces `print_every=1` (write every step). |

## `model`

| Field | Type | Required | Allowed / Range |
| :--- | :--- | :---: | :--- |
| `type` | string | Yes | `single_resolution`, `apriori_refinement`, `dynamic_refinement` |
| `nbox` | integer | Yes | `>= 3` |

## `workpiece`

All distances are in meters.

| Field | Type | Required | Allowed / Range |
| :--- | :--- | :---: | :--- |
| `lo_x`, `hi_x` | number | Yes | `hi_x > lo_x` |
| `lo_y`, `hi_y` | number | Yes | `hi_y > lo_y` |
| `base_height_y` | number | Yes | `> 0` |
| `keep_base_spacing` | boolean | Yes | |

If `keep_base_spacing=true`, particle spacing is computed from `base_height_y/(nbox-1)` and the workpiece is extended in `y` without changing `dx/dy`.

## `tool`

All distances are in meters; angles are degrees.

| Field | Type | Required | Allowed / Range |
| :--- | :--- | :---: | :--- |
| `cutting_speed` | number | Yes | `> 0` | m/s |
| `rake_deg` | number | Yes | | degrees |
| `clearance_deg` | number | Yes | | degrees |
| `length` | number | Yes | `> 0` |
| `height` | number | Yes | `> 0` |
| `tl_y` | number | Yes | | Tool top-left y reference. |
| `fillet_radius` | number | Yes | `>= 0` |
| `mu_friction` | number | Yes | `>= 0` |
| `target_feed` | number | Yes | `> 0` | Depth of cut. |
| `tool_right_clearance` | number | Yes | `>= 0` | Gap from the workpiece left boundary. |
| `tool_x_shift` | number | Yes | | Additional x shift (positive moves toward +x). |

## `time`

| Field | Type | Required | Allowed / Range | Notes |
| :--- | :--- | :---: | :--- | :--- |
| `cut_length` | number | Yes | `> 0` | Used to compute `t_final` when not overridden. |
| `dt_empirical` | number | Yes | `> 0` | Upper bound on dt. |
| `mech_cfl_factor` | number | Yes | `> 0` | Multiplier on the mechanical CFL estimate. |
| `heat_cfl_factor` | number | Yes | `> 0` | Multiplier on the thermal CFL estimate. |
| `dt` | number | No | `> 0` | Overrides dt when present. |
| `t_final` | number | No | `> 0` | Overrides t_final when present. |
